#  我的第一個 Python 學習作品集

這是我在 2026 年開始學習 Python 的實作紀錄。
學測後開始投入時間學習,零基礎從網路上找資源學習。

##  目前包含的功能
* **科大成績計算器**：覺得科大成績算法複雜,寫程式解決繁複的計算。
* **密碼防護系統**：利用 `for` 迴圈與 `range` 實作錯誤次數限制。
* **帳單輸入**：練習清單操作,製作自己的記帳工具。

##  日文聽讀本（網頁）
* `japanese/index.html`：手機、平板都能用的日文單元小工具。
  每一行有日文、中文翻譯，點一下就會念出日文（可切換正常／慢速），上方選單可以跳到任一單元。
  另外有「考試」模式：自選範圍、題型、題數，出四選一的選擇題。
  「教學」裡還有英文口語報告練習（Zero Waste Shu，Speaker 1）：逐句跟讀、重點單字 KK 音標、發音技巧、跟讀模式和計時演練。
